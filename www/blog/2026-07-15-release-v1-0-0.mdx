# Release v1.0.0

BSUI v1.0.0 is now available.

This is the first stable release of BSUI. It establishes the initial public API, component architecture, documentation, and development infrastructure.

## Overview

- Introduced 30+ Bootstrap-compatible React components.
- Added the Prime primitive and shared Utility API.
- Added JSDoc-powered IntelliSense without TypeScript.
- Published the initial Docusaurus documentation and Storybook.
- Added automated testing and CI workflows.

## Changelog

### Added

- Utility props: bg, border, columns, display, flex, float, font, gutter, offset, opacity, overflow, position, rounded, shadow, sizing, spacing, text.
- Helpers: capitalize, classnames, prefix.
- Hooks: useAutohide, useBodyScrollLock, useEscapePress.
- Layout: Container, Grid, Row, Col.
- Forms: Form, Control, Label, Check, Range, Select, FloatingLabel, InputGroup.
- Navigation: Nav, Navbar, Breadcrumb, Dropdown.
- Feedback: Alert, Badge, Progress, Spinner, Placeholder.
- Content: Accordion, Card, ListGroup.
- Overlay: Modal, Collapse, Carousel, Offcanvas.
- Buttons: Button, ButtonGroup, CloseButton.
- Prime primitive.
- Storybook documentation.
- JSDoc-powered IntelliSense.
- Vitest test suite.
- GitHub Actions workflows.
- GitHub Pages deployment.

### Changed

- Replaced `theme` and `variant` with `tone`.
- Standardized the public component architecture and API.
- Unified JSDoc documentation across all components.
