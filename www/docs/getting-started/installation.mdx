# Installation

Install BSUI using npm:

```bash
npm install @promethey/bsui
```

BSUI requires React 19 or higher and Bootstrap 5.1.3.

Install Bootstrap separately:

```bash
npm install bootstrap
```

Import the Bootstrap stylesheet in your application entry point:

```jsx
import "bootstrap/dist/css/bootstrap.min.css";
```

After installation, you can import BSUI components directly:

```jsx
import { Button } from "@promethey/bsui";

function App() {
  return <Button tone="primary">Get Started</Button>;
}
```

## Requirements

Before using BSUI, make sure your project includes:

- React 19+
- React DOM 19+
- Bootstrap 5.1.3+

BSUI does not include Bootstrap styles by default, allowing you to control how Bootstrap is loaded and configured in your application.
