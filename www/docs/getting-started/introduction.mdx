# Introduction

**BSUI** is a modern React component system built on **Bootstrap 5**.

It provides reusable components with a consistent API, utility props, and the flexibility of the Bootstrap ecosystem.

## Features

BSUI provides:

- React components built with Bootstrap 5.
- Consistent component APIs across the library.
- Bootstrap utility classes through component props.
- JSDoc-powered IntelliSense without TypeScript.
- Fully documented components with interactive examples.
- No dependency on Bootstrap JavaScript.

## Requirements

Before installing BSUI, make sure your project includes:

- React `19+`
- React DOM `19+`
- Bootstrap `5.1.3`

## Installation

Install BSUI and Bootstrap:

```bash
npm install @promethey/bsui bootstrap
```

Import Bootstrap styles in your application entry point:

```jsx
import "bootstrap/dist/css/bootstrap.min.css";
```

## Basic Usage

Import components directly from BSUI:

```jsx
import { Button } from "@promethey/bsui";

export default function App() {
  return <Button tone="primary">Get Started</Button>;
}
```
